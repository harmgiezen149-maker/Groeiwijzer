Voor Claude Code
Nieuwe stijl: felle lime/paars/roze/geel op een frisse mintgroene basis, Baloo 2 (koppen) + Nunito (body), platte iconen zonder outline, verhoogde ronde scan-knop in de onderbalk als centrale actie voor "plant toevoegen". Het opvallende afvink-moment (bloem-animatie + kaart die wegschuift) uit §9 moet nog apart als interactie worden toegevoegd.
